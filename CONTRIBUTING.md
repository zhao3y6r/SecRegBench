# Contributing

Corrections and audits are welcome.

Please identify:

- the release version;
- the affected file, scenario ID, family ID, rule ID, or source ID;
- expected and observed behavior;
- supporting official sources or a minimal reproduction;
- whether the issue may change a reported result.

Do not submit production customer data, proprietary institutional procedures,
full copyrighted regulatory documents, credentials, or raw private model
traffic.

Changes that modify dialogue, state, labels, rule interpretations, component
mapping, splits, or scored model outputs require a new version and manifest.
Published hashes are never overwritten silently.
